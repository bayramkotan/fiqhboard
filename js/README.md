# fiqhboard (npm)

**Comparative fiqh of the four Sunni schools** — Hanafi, Maliki, Shafi'i and Hanbali side by side, every ruling in its school's own words, with its source and its evidence.

> **This npm package is a placeholder (0.0.1).** It reserves the name and exposes version information only. The application is the Python package:
>
> ```bash
> pip install fiqhboard
> ```
>
> The npm package will become the JavaScript client of the fiqhboard web API. It carries the same version number as the Python package.

```js
import { info, version } from "fiqhboard";

console.log(version);   // "0.0.1"
console.log(info());    // { name: "fiqhboard", version: "0.0.1", dataLoaded: false, homepage: "…" }
```
